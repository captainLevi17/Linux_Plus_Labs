# Lab 16 - Task Scheduling with Cron and At

## Objective

Master job automation and task scheduling in Linux using the `cron` and `at` daemons. By completing this lab, you will learn how to schedule one-off tasks with `at`, configure recurring personal user tasks with `crontab`, and manage system-wide scheduled jobs using system cron directories and `/etc/crontab`.

By completing this lab, I should be able to:

* Schedule single-execution one-off tasks using `at`, `atq`, and `atrm`
* Configure user-level repeating jobs using `crontab -e` and interpret the 5-field cron timing format
* Differentiate user crontabs (`/var/spool/cron/`) from system-wide crontabs (`/etc/crontab`) and cron directories (`/etc/cron.*/`)
* Properly suppress or redirect scheduled task output to `/dev/null`

## Part 1 - One-Time Task Scheduling (`at`)

The `atd` daemon handles commands configured to run **once** at a specific point in the future.

### `at` Command Quick Reference

| Action | Command / Syntax | Example |
| :--- | :--- | :--- |
| **Schedule One-Off Task** | `at <time_specification>` | `at now +2 minutes` |
| **View Queued Jobs** | `atq` | Lists job IDs, execution time, and user |
| **Remove Queued Job** | `atrm <job_number>` | `atrm 3` |

*Note: Entering an `at` command opens an interactive prompt (`at>`). Type your shell commands and press `Ctrl+D` to submit and exit.*

## Part 2 - Recurring Task Scheduling (`cron`)

The `crond` daemon executes commands repeatedly at scheduled intervals based on crontab files.

### 1. The 5-Field User Cron Syntax

```text
.---------------- minute (0 - 59)
|  .------------- hour (0 - 23)
|  |  .---------- day of month (1 - 31)
|  |  |  .------- month (1 - 12)
|  |  |  |  .---- day of week (0 - 7) (0 or 7 is Sunday)
|  |  |  |  |
*  *  *  *  *  <command-to-execute>
```

### Syntax Symbols

* `*` : Matches every possible value for that field (e.g., `*` in the hour field means "every hour").
* `,` : Comma-separated list for multiple values (e.g., `9,39` in minute field runs at minute 9 and minute 39).
* `*/n` : Step values (e.g., `*/15` in minute field runs every 15 minutes).

### Common Timing Examples

* `37 14 * * 3` : Runs at **2:37 PM every Wednesday**.
* `0 0 1 * *` : Runs at midnight on the 1st of every month.
* `*/10 * * * *` : Runs every 10 minutes.

### 2. User Crontabs vs. System-Wide Cron

| Type | Location | Entry Format | Notes |
| :--- | :--- | :--- | :--- |
| **User Crontab** | `/var/spool/cron/<username>` | 5 timing fields + `command` | Edit via `crontab -e`. Do not edit files directly. |
| **System-Wide Crontab** | `/etc/crontab` | 5 timing fields + **`username`** + `command` | Used by system admins. Avoid editing directly for custom user scripts. |
| **Cron Directories** | `/etc/cron.{hourly,daily,weekly,monthly}/` | Standalone executable scripts | **No 5-field header**. The directory controls the schedule. |

### 3. Output Management
By default, cron sends any output or errors generated by a job via email to the local user account. To suppress or discard job output, redirect standard output and error to `/dev/null`:

```bash
0 2 * * * /usr/local/bin/backup.sh > /dev/null 2>&1
```

## Part 3 - Hands-On Practice Lab

### Step 1: Practice One-Time Scheduling with `at`

1. Schedule a simple task to log the system date 2 minutes from now:
   ```bash
   at now +2 minutes
   ```
   At the `at>` prompt, type:
   ```text
   echo "At job executed at $(date)" >> /tmp/at_test.log
   ```
   Press **`Ctrl + D`** to finish.

2. Verify the job is queued in `atq`:
   ```bash
   atq
   ```

3. (Optional) To delete a queued job:
   ```bash
   atrm <job_number>
   ```

### Step 2: Practice Recurring Scheduling with `crontab`

1. Open your user crontab for editing:
   ```bash
   crontab -e
   ```

2. Add a job that runs every 5 minutes to append uptime info to a file:
   ```text
   */5 * * * * uptime >> /tmp/cron_uptime.log
   ```

3. Save and close the editor. Verify the active user crontab:
   ```bash
   crontab -l
   ```

4. Check the location of your user's crontab file on the system:
   ```bash
   ls -l /var/spool/cron/crontabs/ || ls -l /var/spool/cron/
   ```

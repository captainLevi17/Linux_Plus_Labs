# Linux+ Hands-On Labs

A collection of hands-on Linux administration labs created as part of my preparation for the **CompTIA Linux+ certification**.

The purpose of this repository is to reinforce Linux concepts through practical exercises, moving beyond memorization and into real command-line experience.

Each lab focuses on a specific Linux topic based on the CompTIA Linux+ objectives and is designed to develop practical skills through exploration, problem-solving, and documentation.

---

# Objectives

These labs aim to help develop familiarity with:

- Linux filesystem navigation
- Command-line tools
- System administration tasks
- Configuration and troubleshooting
- User and permission management
- Networking concepts
- Storage management
- Shell scripting
- Security fundamentals

---

# Learning Approach

Each topic follows a practical learning cycle:

1. **Learn**
   - Review course material, documentation, and study notes.

2. **Practice**
   - Complete hands-on tasks in a Linux environment.

3. **Troubleshoot**
   - Investigate problems and understand why solutions work.

4. **Document**
   - Record commands, observations, and lessons learned.

The goal is to build confidence working in a Linux environment rather than simply memorizing commands for an exam.
